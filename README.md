# Resume Website

A personal resume website created using HTML and CSS. This project showcases my educational background, technical skills, projects, certifications, and contact information in a professional web format.

## Features

- Responsive resume design
- Clean and professional layout
- Education details
- Technical skills section
- Projects section
- Certifications and achievements
- Contact information

## Technologies Used

- HTML5
- CSS3
